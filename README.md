# 🎵 iMusica

### YouTube → MP3 / MP4 Converter

**iMusica** is a simple, fast, and modern web application that lets users convert YouTube video links into **MP3 audio** or **MP4 video** files.

> 🎧 Paste a link. Choose a format. Download.

---

## ✨ Features

* 🎵 Convert YouTube videos to **MP3**
* 🎬 Convert YouTube videos to **MP4**
* ⚡ Fast and simple interface
* 🖤 Clean, modern UI
* 🪟 Glassmorphism-inspired design
* 📱 Responsive layout
* 🔗 Simple YouTube URL input
* ⬇️ Easy download experience

---

## 🛠️ Tech Stack

* **HTML**
* **CSS**
* **JavaScript**
* **Node.js**
* **Express.js**
* **yt-dlp**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 2. Enter the project folder

```bash
cd YOUR-REPOSITORY
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the server

```bash
node server.js
```

### 5. Open the website

Go to:

```text
http://localhost:3000
```
